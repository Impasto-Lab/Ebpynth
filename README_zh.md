# Ebpynth 核心机制：Match 与 Vote

简体中文 | [English](./README.md)

## 一、 算法总览（双重循环）

合成引擎交替执行两件事：**“算 Loss $\to$ 改 NNF 表（Match）”** 和 **“用 NNF 表出图（Vote）”**。

```text
【初始状态】：NNF 在最粗层随机初始化（或从上一层粗分辨率升采样继承）
【初始出图】：先用初始 NNF 执行一次投票（vote_image），生成第一张粗糙重建图

外循环（search_vote_iters，默认 6 轮）：
  │
  ├── 1. 算 Loss：将当前重建图与 Target Guide 拼接，计算全图所有像素的基准代价（patch_cost）
  │
  ├── 2. 内循环优化 NNF（patch_match_iters，默认 4 轮）：
  │        全图所有像素一起“向邻居借指针”+“随机盲抽”，谁 Loss 低就更新谁的 NNF 表
  │        （4 轮后，NNF 表里的指针质量提高！）
  │
  └── 3. 投票出图（vote_image）：
           用优化后的 NNF 表，全图 25 票平均生成更清晰的新图
           （图变清晰了，下一轮外循环拿新图去算 Loss 会更准！）
```

## 二、 第一步：给 NNF 指针打分（算 Loss / patch_cost）

目标图像素 $q = (y, x)$ 在 NNF 表里的指针是 Style 图的 $s = (sy, sx)$。

**用加权平方差（SSD）量化这个指针的好坏：**
1. **Target 侧 5×5 小方块**：以 $(y, x)$ 为中心，取 25 个像素的特征（包含：**当前重建图像颜色 + 引导图 Target Guide**）。
2. **Style 侧 5×5 小方块**：以 $(sy, sx)$ 为中心，取 25 个像素的特征（包含：**Style 风格图颜色 + 引导图 Source Guide**）。
3. **两两相减，求差异**：
   $$\text{Loss}(q, s) = \sum_{\Delta \in [-2, 2]^2} \sum_{c} \Big( \sqrt{w_c} \cdot \text{Target}[q + \Delta, c] - \sqrt{w_c} \cdot \text{Style}[s + \Delta, c] \Big)^2$$
   * **Loss 越小**：两块区域越相似，指针越好。
   * **$\sqrt{w}$ 预折叠技巧**：权重开方后提前折叠进特征张量。Source 每层折叠一次，Target 每轮外循环出图后折叠一次。最热的内循环因此退化为普通 SSD，不再需要乘权重。
   * **边界 2 像素环**：Target 边缘用 replicate 填充，这些填充像素在 Source 中没有真实对应。边界的 Loss 因此不能降到 0。这是固有的伪影，不是 bug。

## 三、 第二步：更新 NNF 表（PatchMatch 搜索）

在内循环中，每个像素 $(y, x)$ 找两批“新候选指针”，和当前指针 **PK 决胜**：

### 1. 向邻居借指针（跳泛洪传播 propagate）
* 步长 $j \in \{4, 2, 1\}$，向上下左右 4 个方向借答案。
* **逻辑**：上方邻居 $(y-j, x)$ 指向 Style 的 $(s'_y, s'_x)$。按相对位移推断，Style 的 $(s'_y + j, s'_x)$ 很可能也是好选择。若越界，直接标记为无效，Loss 设为 $+\infty$，自动淘汰。
* **4 方向批处理**：现任的 Loss 直接复用。单次 `patch_cost` 只为 4 个新方向的候选批量打分。再把现任的 Loss 堆叠在首位，形成 5 候选张量，用 `argmin(0)` 决胜。平局时 `argmin(0)` 返回下标 0，保留现任。

### 2. 在周围盲抽（随机搜索 random_search）
* 半径 $R$ 按几何级数倍增，从 1 增到源图半维 $\frac{1}{2}\max(H, W)$。在当前指针周围 $s \pm R$ 范围内随机抽一个新指针，并截断在合法边界内。
* 同样算 Loss。新指针更优就立即更新，用来跳出局部极值。

### 3. 均匀性惩罚（Uniformity）
* 打分公式加入占用惩罚项： $\text{Score} = \text{Cost} + \lambda \times \frac{\text{BoxFilter}(\Omega)[s]}{\text{Ideal}}$。
* **用卷积提速（`score` 快 19 倍）**：以 $s$ 为中心的 25 像素占用和，是对 $\Omega$ 的盒滤波。一次 `avg_pool2d(divisor_override=1)` 算出全图的 25 像素总和。25 次 Gather 因此变成 1 次池化求和加 1 次 Gather。均值除数 $25$ 预先折叠进惩罚系数常数。
* 指针变更时，旧位置的 25 个像素占用 $-1$，新位置的占用 $+1$。代码把旧减和新加融合，遍历 25 个偏移，各做 1 次 `scatter_add_`，共 25 次。传统的旧减新加要 50 次 scatter，这里减半。

## 四、 第三步：用 NNF 投票出图（Voting / vote_image）

以 `patch_size = 5`（ $5 \times 5 = 25$ 像素）为例，追踪目标图单个像素 $(y, x)$ 如何得到最终颜色。

### 1. 谁决定 $(y, x)$ 的颜色？
* $(y, x)$ 自己是一个 Patch 的中心。
* 它周围所有离它不超过 2 格的像素（左邻居、右邻居、正上方、左上角等），各自以自己为中心画 $5 \times 5$ 方块。这些方块**都会盖住 $(y, x)$**。
* 对于图像内部的像素，共有 **25 个不同的 Patch 覆盖 $(y, x)$**。靠近边界或角落的像素，覆盖数少于 25 个。

### 2. 这 25 个 Patch 如何“投票”？
NNF 已经为这 25 个 Patch 在 Style 图里找到了最像的位置。每个 Patch 按相对方位，取出对应的 Style 颜色：
1. **$(y, x)$ 自己的 Patch**：NNF 指向 Style 的 `(100, 200)`。它投票：“ $(y, x)$ 是我的中心，颜色应该是 **Style 的 `(100, 200)`**”。
2. **上方邻居 $(y-1, x)$ 的 Patch**：NNF 指向 Style 的 `(50, 80)`。它投票：“ $(y, x)$ 在我的正下方 1 格，颜色应该是 **Style 的 `(51, 80)`**”。
3. **左上角邻居 $(y-2, x-2)$ 的 Patch**：NNF 指向 Style 的 `(10, 30)`。它投票：“ $(y, x)$ 在我的右下方 (2, 2) 格，颜色应该是 **Style 的 `(12, 32)`**”。
*…… 其余 22 个邻居同理，按相对方位取色。*

### 3. 计算最终颜色（按有效票数取平均）
像素 $(y, x)$ 把收到的所有有效票的颜色相加，再除以该像素实际收到的有效票数 $N$：
$$\text{Output}[y, x] = \frac{1}{N_{y, x}} \sum_{i=1}^{N_{y, x}} \text{Color}_i \quad (内部像素 N=25，边界像素按实际覆盖数归一化)$$
*代码用 25 个固定偏移做 NNF 切片和 Gather，累加颜色张量 `acc` 和计数张量 `cnt`，最后用 `acc / cnt` 求平均。这样不用 Scatter，边缘也不会变暗。*
