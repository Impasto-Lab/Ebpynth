# Ebpynth 核心机制：Match 与 Vote

## 一、 算法核心运作总览（双重循环）

整个合成引擎本质上是在不断交替执行 **“算 Loss $\to$ 改 NNF 表（Match）”** 与 **“用 NNF 表出图（Vote）”**：

```text
【初始状态】：NNF 在最粗层随机初始化（或从上一层粗分辨率升采样继承）
【初始出图】：先用初始 NNF 执行一次投票（vote_image），生成第一张粗糙重建图

外循环（search_vote_iters，默认 6 轮）：
  │
  ├── 1. 算 Loss：将当前重建图与 Target Guide 拼接，计算全图所有像素的基准代价（patch_cost）
  │
  ├── 2. 内循环优化 NNF（patch_match_iters，默认 4 轮）：
  │        全图所有像素一起“向邻居借指针”+“随机盲抽”，谁 Loss 低就更新谁的 NNF 表
  │        （4 轮后，NNF 表里的指针质量大幅提升！）
  │
  └── 3. 投票出图（vote_image）：
           用优化后的 NNF 表，全图 25 票平均生成更清晰逼真的新图
           （图变清晰了，下一轮外循环拿新图去算 Loss 会更精准！）
```

## 二、 第一步：怎么给 NNF 指针打分？（算 Loss / patch_cost）

假设目标图像素 $q = (y, x)$，当前在 NNF 表里记录的指针是 Style 图的 $s = (sy, sx)$。

**这个指针选得好不好？通过加权平方差（SSD）量化：**
1. **Target 侧 5×5 小方块**：以 $(y, x)$ 为中心，提取 25 个像素特征（包含：**当前重建图像颜色 + 引导图 Target Guide**）。
2. **Style 侧 5×5 小方块**：以 $(sy, sx)$ 为中心，提取 25 个像素特征（包含：**Style 风格图颜色 + 引导图 Source Guide**）。
3. **两两相减算差异**：
   $$\text{Loss}(q, s) = \sum_{\Delta \in [-2, 2]^2} \sum_{c} \Big( \sqrt{w_c} \cdot \text{Target}[q + \Delta, c] - \sqrt{w_c} \cdot \text{Style}[s + \Delta, c] \Big)^2$$
   * **Loss 越小**：说明两块区域越相似，指针越优质。
   * **$\sqrt{w}$ 预折叠技巧**：权重开方提前折叠进特征张量（Source 每层折叠一次，Target 每轮外循环出图后折叠一次），最热内循环直接退化为普通 SSD，彻底消除乘法算子。
   * **边界 2 像素环**：Target 边缘 replicate 填充在 Source 中无真实对应，边界代价恒无法归零（固有伪影，非 bug）。

## 三、 第二步：怎么更新 NNF 表？（PatchMatch 搜索）

在内循环中，每个像素 $(y, x)$ 会寻找两拨“新候选指针”来跟当前指针 **PK 决胜**：

### 1. 向邻居借指针（跳泛洪传播 propagate）
* 步长 $j \in \{4, 2, 1\}$ 向上下左右 4 个方向借答案。
* **逻辑**：若上方邻居 $(y-j, x)$ 指向 Style 的 $(s'_y, s'_x)$，根据相对位移推断，Style 的 $(s'_y + j, s'_x)$ 极大概率也是好选择（若越界则直接标记无效，Cost 赋为 $+\infty$ 自动淘汰）。
* **4 方向批处理**：现任代价直接复用，**单次 `patch_cost` 仅为 4 个新方向候选批量打分**，随后在首位堆叠现任代价形成 5 候选张量，用 `argmin(0)` 决胜（平局优先返回下标 0 默认保留现任）。

### 2. 在周围盲抽（随机搜索 random_search）
* 半径 $R$ 几何倍增（从 1 倍增至源图半维 $\frac{1}{2}\max(H, W)$），在当前指针周围 $s \pm R$ 范围内随机抽一个新指针（并截断在合法边界内）。
* 同样算 Loss，若更优则立即更新表，用于跳出局部极值。

### 3. 均匀性惩罚（Uniformity）
* 打分公式加入占用惩罚项： $\text{Score} = \text{Cost} + \lambda \times \frac{\text{BoxFilter}(\Omega)[s]}{\text{Ideal}}$。
* **卷积伪装（提速 19x）**：以 $s$ 为中心的 25 像素占用和是对 $\Omega$ 的盒滤波，用一次 `avg_pool2d(divisor_override=1)` 算出全图 25 像素总和，将 25 次 Gather 塌缩为 1 次池化求和 + 1 次 Gather（均值除数 $25$ 预先折叠进惩罚系数常数中）。
* 指针变更时，旧位置 25 像素占用 $-1$、新位置 $+1$（将旧减与新加融合，遍历 25 个偏移执行 25 次单次 `scatter_add_`，相比传统的旧减新加 50 次 scatter 开销减半）。

## 四、 第三步：怎么用 NNF 投票出图？（Voting / vote_image）

以 `patch_size = 5`（ $5 \times 5 = 25$ 像素）为例，追踪目标图单个像素 $(y, x)$ 如何拿到自己的最终颜色：

### 1. 谁有资格决定 $(y, x)$ 的颜色？
* $(y, x)$ 自己是一个 Patch 的中心；
* 它的左邻居、右邻居、正上方、左上角等周围所有离它不超过 2 格的像素，以它们为中心画 $5 \times 5$ 方块，**全都会把 $(y, x)$ 盖在里面**；
* 对于图像内部像素，一共有 **25 个不同的 Patch 共同覆盖像素 $(y, x)$**（靠近边界或角落的像素覆盖数则少于 25 个）。

### 2. 这 25 个 Patch 是怎么各自“投票”的？
NNF 已经帮这 25 个 Patch 在 Style 图里找到了最像的位置。它们根据相对方位去抓出对应的 Style 颜色：
1. **$(y, x)$ 自己的 Patch 投票**：NNF 指向 Style 的 `(100, 200)`。它投一票：“ $(y, x)$ 是我的中心，颜色应该是 **Style 的 `(100, 200)`**”。
2. **上方邻居 $(y-1, x)$ 的 Patch 投票**：NNF 指向 Style 的 `(50, 80)`。它投一票：“ $(y, x)$ 在我的正下方 1 格，颜色应该是 **Style 的 `(51, 80)`**”。
3. **左上角邻居 $(y-2, x-2)$ 的 Patch 投票**：NNF 指向 Style 的 `(10, 30)`。它投一票：“ $(y, x)$ 在我的右下方 (2, 2) 格，颜色应该是 **Style 的 `(12, 32)`**”。
*…… 其余 22 个邻居同理按相对方位抓取。*

### 3. 计算最终颜色（自适应票数平均）
像素 $(y, x)$ 将收到的所有有效票颜色累加，除以该像素实际被覆盖的有效票数 $N$：
$$\text{Output}[y, x] = \frac{1}{N_{y, x}} \sum_{i=1}^{N_{y, x}} \text{Color}_i \quad (内部像素 N=25，边界像素按实际覆盖数归一化)$$
*实现上通过 25 次 NNF 固定偏移切片与 Gather 累加颜色张量 `acc` 与计数张量 `cnt`，最终通过 `acc / cnt` 求均值，完全免除 Scatter 且边缘绝不发暗。*
